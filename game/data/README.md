# Игровые данные (баланс)

Все числа игры — здесь, в JSON. Код их только читает. Поменяли значение → перезапустили игру (`npm run dev` подхватит сам).
При запуске `index.ts` проверяет данные: опечатка в id, неизвестный класс/ресурс/эпоха — игра не стартует и пишет, где ошибка.

После правок баланса: `npm run balance` — ~50 матчей ботов параллельно и сводка (типы и время побед, эпохи, окупаемость каждого юнита, популярность технологий, уровни ботов); `npm test` — детерминизм, механики, согласованность данных.

## Единицы

| В JSON | Значит |
|---|---|
| `range`, `sight`, `splash` | клетки (1 клетка ≈ размер дома 1×1) |
| `speed` | клеток в секунду |
| `reload`, `trainTime`, `buildTime`, `researchTime`, любое `…Time`, `hold`, `interval` | секунды (точность 0.1 с) |
| `bonus` | % урона по классу цели: `{ "cavalry": 300 }` — втрое по коннице, 100 — обычный |
| `cost` | ресурсы: `food`, `wood`, `stone`, `iron`, `gold`, `energy` |
| `age` | id эпохи из `ages.json`: `primitive`, `ancient`, `medieval`, `imperial`, `industrial`, `mechanized`, `modern`, `future` |

## Файлы

| Файл | Что |
|---|---|
| `units.json` | юниты: здоровье, атака, броня, дальность, перезарядка, скорость, обзор, цена, время, бонусы, особые свойства |
| `buildings.json` | здания: цена, прочность, размер, кого обучают (`trains`), какие ресурсы принимают (`drop`), население (`pop`), атака башен |
| `techs.json` | технологии: направление (`mil`/`eco`/`sci`/`civ`), эпоха, цена, время, эффекты |
| `ages.json` | эпохи по порядку, цена перехода В эпоху, время перехода |
| `economy.json` | добыча, переноска, стартовые ресурсы, пшеница, рынок, торговля, энергия, лимиты |
| `settlements.json` | рост поселения (посёлок → … → мегаполис) и бонусы уровней |
| `world.json` | рельеф (холмы, лесное укрытие), регионы, случайные события |
| `map.json` | генерация карты: озёра, горы, леса, залежи, ресурсы у базы, точки баз |
| `victory.json` | условия победы; `minAge` — с какой эпохи возможна экономическая/культурная победа |
| `culture.json` | направления развития, уровни культуры, слоты исследований на эпоху |
| `diplomacy.json` | отношения (война … союз), время ответа на предложение, дань |
| `ai.json` | уровни ботов, их характер, кем отвечать на какой класс врага, `diplomacy` — когда боты мирятся и нападают |

## Юнит (`units.json`)

```json
"knight": {
  "name": "Рыцарь", "icon": "♞",
  "class": "cavalry",        // worker, trade, infantry, spear, ranged, cavalry, siege, armor, air, animal
  "age": "medieval",
  "hp": 130, "attack": 11, "armor": 4,
  "range": 1.5,              // ближний бой ≈ 1.5
  "reload": 1.8, "speed": 1.8, "sight": 7,
  "cost": { "food": 80, "iron": 40, "gold": 50 },
  "trainTime": 24,
  "bonus": { "infantry": 150 }
}
```

Особые свойства (по желанию): `air` — летает; `hitsAir` — может ли бить авиацию (по умолчанию да, если стреляет дальше 2 клеток);
`airOnly` — бьёт только авиацию; `pierce` — игнорирует броню; `noPop` — не занимает население (дроны, лимит — `economy.json → droneCap`);
`splash` — урон по площади (клетки), соседи цели получают половину; `animal` — скот.

Чтобы юнита можно было обучить, добавьте его id в `trains` нужного здания в `buildings.json`.
Модель и анимации юнита подключаются отдельно — см. `assets/README.md`.

## Эффекты технологий (`techs.json → effects`)

`atk` +атака, `atkPct` +% урона, `armor` +броня, `hp` +% здоровья войск, `vilHp` +% здоровья жителей, `speed` +% скорости,
`cavSpeed` +% скорости конницы, `gather` +% добычи, `farm` +% урожая, `mine` +% камня/железа/золота, `carry` +переносимое,
`research` −% времени исследований, `bldHp` +% прочности зданий, `housePop` +население на дом, `tcPop` +население у центра,
`sight` +обзор, `range` +дальность башен и центров, `siege` +% урона по зданиям, `ageCost` −% цены эпох, `energy` +% выработки электростанций.
