# Выкладка в сеть (Coolify)

Игра разворачивается **одним контейнером**: Node-сервер отдаёт собранную игру (статика Nuxt) и принимает сетевую игру по WebSocket на пути `/ws` — тот же домен и порт. HTTPS/WSS обеспечивает Coolify.

## Шаги в Coolify

1. **+ New → Application** → источник — ваш GitHub (GitHub App или публичный URL репозитория), ветка `master`.
2. **Build Pack: Dockerfile** (файл `Dockerfile` в корне).
3. **Ports Exposes: `3000`**.
4. **Domains:** ваш домен, например `https://epohi.example.com` (Coolify сам выпустит сертификат).
5. **Health check** (вкладка Health Checks): путь `/health`, порт `3000` — или ничего не менять: в образе уже есть `HEALTHCHECK`.
6. **Deploy.** Первая сборка — 3–5 минут: ставятся зависимости, скачиваются паки KayKit с GitHub, собирается Nuxt.

Переменные окружения **не нужны**. Необязательные:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `PORT` | `3000` | порт внутри контейнера (тогда поменять и Ports Exposes) |

WebSocket через прокси Coolify (Traefik/Caddy) работает без настроек. Ссылки на комнаты вида `https://домен/room/abc` открываются напрямую.

## Что происходит при сборке

- `npm ci` → `node scripts/assets/build.mjs --prune` — модели из `assets/packs` (в репозитории) и паки KayKit/Kenney (скачиваются с GitHub), текстуры земли из `assets/textures`. `--prune` оставляет только файлы, на которые ссылается игра (≈70 МБ вместо ≈130).
  Если что-то не скачалось, сборка не падает — эти юниты рисуются процедурно (видно в логе сборки: «Юниты с моделями: N/35»).
- `nuxt generate` — статика игры в `.output/public`.
- Итоговый образ: Node 22 + библиотека `ws` + код сервера (`game/`) + статика. Запуск от непривилегированного пользователя.

## Ресурсы

Сервер лёгкий: статика и WebSocket. Каждая идущая сетевая партия — это симуляция на сервере (10 тиков в секунду, десятки МБ памяти). Для начала хватит 1 vCPU / 1 ГБ RAM; одиночная игра сервер не нагружает вовсе — она целиком в браузере.

## Локально (проверить образ)

```
docker build -t epohi .
docker run --rm -p 3000:3000 epohi
# http://localhost:3000
```

Без Docker: `npm run assets && npm run generate && npm start` → http://localhost:3000 (порт — `PORT`).
